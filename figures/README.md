# Figures Folder

## Purpose

This folder contains all visualizations generated during the Exploratory Data Analysis (EDA) phase.

## Contents

### count_year_plot.png

Distribution of trips by year.

### count_plot_month.png

Monthly ride demand analysis.

### Year_month_count.png

Year-month trend showing trip volume over time.

### count_plot_weekday.png

Trip distribution across weekdays.

### heatmap_day_hour.png

Heatmap illustrating ride demand by day of week and hour of day.

### correlation_map.png

Correlation matrix showing relationships between key trip variables such as:

- Trip Distance
- Trip Duration
- Passenger Fare
- Tips
- Driver Pay

## Purpose of Visualizations

These figures help identify:

- Temporal trends
- Demand fluctuations
- Customer travel patterns
- Relationships between operational and financial variables
