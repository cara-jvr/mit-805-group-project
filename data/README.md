## Purpose

This folder contains the raw data files and supporting reference data used in the project.

## Contents

### FHVHV Trip Data

Monthly New York City For-Hire Vehicle High Volume (FHVHV) trip data stored in Apache Parquet format.

### HVFHV_Trip_Data_Data_Dictionary

Contains descriptions, definitions, and metadata for all dataset attributes used in the analysis.

### taxi_zone_lookup.csv

Reference table containing Taxi Zone IDs and their corresponding boroughs and zones.

## Dataset Summary

- Dataset Type: Transportation / Mobility Data
- Format: Parquet
- Time Period: January 2024 – December 2025
- Raw Records: 483.06 million trips
- Compressed Size: 10.93 GB
- Uncompressed Size: 13.41 GB

## Notes

Due to size constraints, large data files may not be stored directly in GitHub and can be accessed from the original source.
